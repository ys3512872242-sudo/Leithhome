# Third-party skill sources

Leithhome includes adapted runtime guidance derived from the following real GitHub Agent Skills. The adaptations remove setup flows and game-specific output formats that conflict with Leithhome, while retaining the cited behavioral mechanisms.

## AI Companion

- Source: https://github.com/xnydl/ai-companion-skill
- License: MIT
- Copyright: Copyright (c) 2026 xnyld
- Used concepts: persistent character embodiment, proactive conversation, natural memory callbacks, and avoiding assistant/customer-service voice.

## Velvet Ascent

- Source: https://github.com/ruijayfeng/velvet-ascent-skill
- License: MIT
- Used concepts: relationship-stage-gated escalation, desire stance, character-specific trigger/reaction/tell patterns, scene-earned intimacy, female-oriented sensory focus, agency, and relational consequences.

## CC Harness Skills

- Source: https://github.com/LearnPrompt/cc-harness-skills
- License: MIT
- Copyright: Copyright (c) 2026 carl
- Used concepts: selective context retention, durable-memory extraction, periodic memory consolidation, and keeping prompt-facing indexes concise. Leithhome applies these as local context controls rather than injecting the coding-oriented continuation template into companion chat.

These adaptations are not presented as unmodified upstream releases.
